[BEGIN DESCRIPTION]
Your website’s code may not have started when a PHP runtime vulnerability is triggered.

CVE-2026-109618 involves out-of-memory handling that can interrupt partially initialized internal data. Cleanup may then treat that unfinished state as valid. Under exploitable conditions, a crafted request can lead to unauthenticated remote code execution (RCE).

The pre-application attack scenario was demonstrated with Apache mod_php. Other deployments have different conditions. Code execution starts with the web worker’s permissions; root access is not automatic.

PHP released the security fix on October 21, 2026. Update the PHP runtime and verify that the service actually serving requests has loaded the fix. A firewall does not repair the underlying runtime.
