[BEGIN DESCRIPTION]
A request ends. Its memory is released. A reference can still remain inside the PHP worker.

CVE-2026-109619 involves stale worker-wide state that can point to memory from a completed request. When the same worker handles another request, an early operation may use that reference before normal initialization resets it.

That is use-after-free: accessing memory after its lifetime has ended. Under exploitable conditions, the error can lead to remote code execution (RCE). The exact trigger depends on the deployment and internal state involved. Initial execution uses the worker’s permissions; root access is not automatic.

Patch the PHP runtime, restart affected workers and verify the version actually serving requests.
