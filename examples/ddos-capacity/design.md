# Design: a shared link under pressure

Angle: track a normal packet through a physical network model as distributed
traffic consumes the only shared exit.

Palette: background #0b1220, panel #111e30, metal #52657a, edge #8ca1b8,
foreground #eef3f8, muted #b7c6d7, normal #4dd4ff, attack #ff7a59,
success #a5dfbc. Cyan and orange encode the two stipulated roles; they are
not intrusion-detection measurements. Explicit normal/attack labels repeat them.

Type: locally embedded Oswald 500/600 for headings and IBM Plex Mono 400/500
for labels. Captions use Oswald 400 at 50 px, at most two measured lines.
Headings 76 px; support text 36 px; scene and equipment labels at least 28 px.
The safe area is x90..900/y240..1480. Captions occupy y1320..1475.

The main figure is a vertical network assembly: source devices at the near end,
branching paths converge on a router queue, a narrow uplink reaches the server.
The visible depth and a gentle dolly make topology physical; rotation never
competes with text. Dark neutral metal, broad soft key/fill lighting and
emissive signal markers preserve readable silhouettes.

Focal element: the shared link and its occupancy. Edge anchors: top chapter
eyebrow and headline, bottom captions. Supporting details: projected object
labels and a capacity track. Background: solid dark field and a sparse
physical ground grid. No stock hacker imagery, text walls, logos or music.

Lighting and geometry are procedural original work. No bloom, temporal
postprocessing, glass, motion blur or external HDRI in this first profile.

## Cinematic event treatment

At frame 463 (15.433 s), amber capacity anticipates saturation. The first packet
loss at frame 478 (15.933 s) triggers a red outlined warning triangle,
“PACKETS DROPPED / LINK CAPACITY EXCEEDED”, a brief camera push and an expanding
ring at the queue. The banner holds through frame 549. At frame 928 (30.933 s),
a modeled legitimate request is dropped; “REQUEST LOST / SERVER STILL ONLINE”
holds through frame 1011. Each cue enters over nine frames and fades over eight.
The server remains green and operational. The effect is a local visual impact;
there is no added sound or full-screen flash. Narration and the 60-second timing
remain unchanged.
