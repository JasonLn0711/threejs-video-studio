# Measured storyboard

Source: reference/shotlist_60s.json (preserved). Adopted timing: film.json.

## S01 — LOCKED FRONT DOOR

- Time: 0.000–3.500 seconds; frames [0, 105).
- Camera: Slow 6% dolly-in toward immense gunmetal vault, perfectly centered vertical symmetry
- Visual: Black frame to cold-blue security monolith. Only one slit of cyan light; no hacker cliché.
- Narration: Microsoft's front door required a VPN.
- Acceptance: Dramatization of actual VPN restriction on Titan FRONTEND, not a screenshot.

## S02 — THE SIDE ENTRANCE

- Time: 3.500–7.200 seconds; frames [105, 216).
- Camera: Slow orbit 30 degrees around vault edge, revealing an unguarded glowing side port
- Visual: A thin amber signal travels outside the sealed front door toward a small server socket.
- Narration: But its analytics API was still reachable online.
- Acceptance: API was externally reachable; do not imply there was no authentication.

## S03 — AI FINDS A LEAD

- Time: 7.200–10.933 seconds; frames [216, 328).
- Camera: Match-cut side port into elegant network graph, then glide past floating archived document edges
- Visual: Precise subdomain node geometry. One file marked ARCHIVED CONFIG; tiny 56 ROUTES/SOURCES not literal if inaccurate: display 56 TABLE DEFINITIONS only.
- Narration: An AI agent found it for a sixteen-year-old researcher.
- Acceptance: Antares discovered public endpoint; archived Superset config contained 56 table definitions.

## S04 — TEN DAYS OF ERRORS

- Time: 10.933–15.033 seconds; frames [328, 451).
- Camera: Three precise rhythmic whip pans between laser-cut translucent panels, then decelerate
- Visual: Fields illuminate one by one; each panel shows a sanitized rejection icon. No spinning terminal text.
- Narration: For ten days, it worked through one security check after another.
- Acceptance: Actual service inspected JWT claims but failed to authenticate signature.

## S05 — THE MISSING SIGNATURE

- Time: 15.033–19.433 seconds; frames [451, 583).
- Camera: Single deliberate dolly lateral across three suspended glass layers; rack-focus onto empty signature socket
- Visual: Header glass and Payload glass glow; final SIGNATURE chamber physically empty, unlatching in silence.
- Narration: The server checked the token's claims, but never verified its signature.
- Acceptance: Use non-actionable placeholder JWT visuals; DO NOT show production endpoint or real keys.

## S06 — THE WRONG ASSUMPTION

- Time: 19.433–22.300 seconds; frames [583, 669).
- Camera: Camera subtly pushes down endless corridor of identical error cards
- Visual: Email-shaped identities fold to dark cards; one solitary cursor waits below.
- Narration: Still, every email-style username failed.
- Acceptance: AI searched email-format UPNs unsuccessfully.

## S07 — ONE HUMAN HUNCH

- Time: 22.300–25.933 seconds; frames [669, 778).
- Camera: Locked-off intimate desk composition, 2% creeping push; cursor blinks then four letters appear
- Visual: One anonymous figure in darkness, only keyboard edge and fingertip implied; large perfectly upright admin text.
- Narration: Then the researcher tried a simpler name. Admin.
- Acceptance: Human researcher hypothesized local username mapping; no depiction of actual Faav identity.

## S08 — QUERY RETURNS ONE

- Time: 25.933–28.467 seconds; frames [778, 854).
- Camera: Hard cut to absolute stillness; slow micro push on one bright digit
- Visual: White numeral 1 in center, tiny caption QUERY EXECUTED AS LOCAL ADMIN.
- Narration: This time, a test query returned one.
- Acceptance: 1 depicts bounded proof-of-execution SELECT 1 result, not 17 trillion records returned.

## S09 — UNIMAGINABLE SCALE

- Time: 28.467–35.733 seconds; frames [854, 1072).
- Camera: Unbroken fast-to-slow crane pullback revealing exactly 17 illuminated data towers receding into darkness
- Visual: Repeated precision-grid architecture. Count stabilizes at 17.3T; data abstraction, never actual personal records.
- Narration: That meant seventeen databases, with an estimated seventeen point three trillion rows potentially reachable.
- Acceptance: Value is metadata-derived potential exposure, NOT leaked/downloaded records; preserve qualifier in frame.

## S10 — RESPONSIBLE DISCLOSURE

- Time: 35.733–39.133 seconds; frames [1072, 1174).
- Camera: Elegant reverse dolly from infinite data towers back into tiny report envelope on dark desk
- Visual: Warm neutral white over soft blue. A single minimalist outlined REPORT SUBMITTED emblem; no fake email screenshot.
- Narration: He checked limited samples, then reported the flaw.
- Acceptance: Researcher used bounded samples and metadata; no full data dumping shown.

## S11 — ENDPOINT RESTRICTED

- Time: 39.133–43.833 seconds; frames [1174, 1315).
- Camera: Two measured lateral moves: security shutter closes; award date appears without triumph confetti
- Visual: Cold portal fades to secure outline. Understated MSRC timeline cards, illustrative not official Microsoft notice.
- Narration: Microsoft restricted access and awarded him five thousand dollars.
- Acceptance: Microsoft restricted endpoint on Sep 9 according to researcher; $5,000 award Sep 17.

## S12 — THE LAST QUESTION

- Time: 43.833–49.233 seconds; frames [1315, 1477).
- Camera: Return to identical front-door framing from S01; stop exactly before resolving scanner light
- Visual: The signed-ID slot is empty; tiny amber pin of light where a signature should be. Last frame matches opener.
- Narration: So checking claims isn't enough. You have to verify the signature.
- Acceptance: Final moral is verification of identity proof, not distrust of JWT technology itself.
