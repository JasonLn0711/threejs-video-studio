Voice: am_michael / en-us / speed 1.0. Timing follows generated audio.

## 1

You updated WordPress. But what about the PHP running it?

## 2

WordPress, themes, and plugins contain code. PHP runs their server-side code.

## 3

A green WordPress update badge does not confirm that PHP's security fixes are installed. The runtime can have a vulnerability even when WordPress itself is current.

## 4

Start with Tools, Site Health, Info, then Server. Note the PHP version.

## 5

Then ask your host or server administrator to confirm the installed security fixes.

## 6

Vendors may patch an older package without adopting the newest PHP version. Managed hosting may handle updates for you.

## 7

Before an upgrade, back up and test compatibility. Afterward, verify the PHP actually serving your site.
