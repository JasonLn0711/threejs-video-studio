# Design contract

Concept: pull back from a reassuring WordPress update light to reveal the separately maintained PHP runtime beneath it.

Preserve the series palette (#070B14 navy, #74B8C6 cyan, #E0A96B amber) and local Oswald / IBM Plex Mono fonts. WordPress core alone has a green update indicator. PHP status remains unknown; cyan denotes a component, not a security verdict. One machined website assembly with application modules and an independent runtime substrate. Split/explode the structure to expose the maintenance boundary; retain object identity across all seven shots. Use projected labels and physical patch components; no fabricated admin screenshots.

Critical copy stays within x=100..890, y=250..1480. Captions use 40px IBM Plex Mono, maximum two lines. Headlines use Oswald 76px. The 3D object is the visual focal point in the central band; explanatory headlines and status labels provide anchors. The footer labels the scene as conceptual. Changes in focus and camera position follow the spoken explanation. Motion is frame-derived and deterministic; no wall clock or random inputs.

Motion references: hyperframes-animation/adapters/three.md; rules/3d-camera-flight.md; rules/depth-of-field-blur.md. The shared continuous world avoids iframe/subcomposition seams; seven deterministic camera poses define the shots.
